# pay262.github.io
🌐 GitHub Pages 静态网页仓库

在线预览：**https://pay262.github.io**

## 📋 项目简介
本仓库为个人静态网页集合，全部由 HTML、CSS、原生JavaScript 编写，托管于 GitHub Pages。
包含多个工具页面、演示页面，所有文件直接静态运行，不需要后端服务。

## 🛠 技术栈
- HTML5
- CSS3
- Vanilla JavaScript
- 部署：GitHub Pages(main分支)

## 🚀 本地运行预览
项目为纯静态文件，**无需安装依赖**。

Python简易服务器
bash
cd pay262.github.io
python3 -m http.server 8080

浏览器打开 `http://127.0.0.1:8080`

也可使用VSCode LiveServer插件直接预览。

## ✨ 使用说明
1. 访问站点：直接打开 GitHub Pages链接
2. 修改页面：修改对应目录下 `.html` / `.css` / `.js` 文件
3. 提交推送至main分支，GitHub Pages会自动部署更新。

> ⚠️ 提示：仓库内仅存放静态前端文件，不存放真实密钥、隐私数据。
