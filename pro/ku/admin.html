使用说明：
1. 后台密码：首次使用会引导你设置密码，哈希存本地，建议配合服务器 HTTP Basic Auth。
2. 置顶：勾选后强制排最前，可设小时/天/月，过期自动取消。
3. 历史版本特点：在编辑弹窗「📜 历史版本」区填写一行小字描述，前端展示在版本号下方。
4. 拖拽排序：按住卡片左侧 ☰ 图标拖动。
5. 撤销：删除后 5 秒内可撤销。
6. 链接健康检查：批量检测下载链接可达性（no-cors 模式，仅供参考）。
7. 操作日志：记录最近 200 条增删改记录。
8. CSV 导入：支持 name,icon,desc,category,version,androidUrl,pwd,iosUrl,addedAt 字段。
9. 快捷键：Ctrl + S 保存正在编辑的表单。
