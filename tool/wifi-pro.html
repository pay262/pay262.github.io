📶 WiFi控制台
  1. 长按上方蓝色按钮
  2. 选择"添加到书签"或"收藏"
  3. 名称可改为"WiFi控制台"
  4. 保存到书签栏或书签文件夹
支持的浏览器：任意手机浏览器（Chrome / Edge / 夸克 / UC / 三星）
不需要：装 App、装扩展、root 手机

🎯 使用方法（每次）

  1. 手机连上随身WiFi
  2. 打开 192.168.0.1
  3. 等待后台页面加载完成
  4. 点书签里的"WiFi控制台"
  5. 面板自动弹出 ✅

Q：点了没反应？
确保先打开 192.168.0.1 页面，再点书签。书签只能在设备后台页面里执行。

Q：能改串/改 IMEI 吗？
不能。手机端只支持查看状态和锁频/切卡。改串需要在电脑端用 AT 指令。

Q：iOS Safari 上点了没反应？
iOS 会剥离 javascript: 前缀。打开书签编辑，手动在 URL 前面补上 javascript: 即可。
